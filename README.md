# Cross-organ multiple-in-one parallel compressed sensing magnetic resonance imaging

Abstract: Recent advances in deep learning-based parallel compressed sensing magnetic resonance imaging (p-CSMRI) have significantly improved reconstruction quality. However, existing methods train neural networks individually for each organ, resulting in poor adaptability and generalization of the trained networks. How to train a unified network using cross-organ datasets remains a significant challenge. To address this, we propose CMPNet, a cross-organ multiple-in-one deep unfolding p-CSMRI network. This unified framework implements a p-CSMRI iterative algorithm via three specialized modules: an auxiliary variable module, a prior module, and a data consistency module. Recognizing that p-CSMRI systems often employ varying acceleration factors for different organs, leading to organ specific artifact patterns, we introduce an artifact generator. It extracts and integrates artifact features into the data consistency module, thereby enhancing the discriminative ability of the overall network. For the prior module, we design an organ structure prompt generation submodule that leverages structural features extracted from the Segment Anything Model (SAM) to create organ specific prompts. These prompts are then incorporated into the prior module through an organ structure aware Mamba submodule. Comprehensive evaluations on a cross-organ dataset demonstrate that CMPNet achieves state-of-the-art reconstruction performance across multiple anatomical structures using a single unified model.
